CHRONO BLITZARCADE COLLECTION — DEMO

VERSION 2.8.1 — NEON UPRISING：前方向2回でダッシュ、走行中の攻撃で強打＆確定ダウン。起動時は最初のクリック / キーでスタート（音楽開始）

ブラウザだけで動く 2 本立てのアーケードゲームです。1 対 1 の 2D 対戦格闘「OVERDRIVE」と、1 人用ベルトスクロールアクション「NEON UPRISING」をゲーム選択画面から遊べます。 画像・音声はゲーム本体と同じ場所の data フォルダにまとめてあり、サーバーや追加インストールは不要です。
A browser-only arcade collection: the 1-on-1 fighter OVERDRIVE and the side-scrolling beat 'em up NEON UPRISING, both running from one HTML file and a folder of asset packs, with nothing to install.

▶ PLAY DEMO / デモをプレイ

初回は約 135MB のデータを読み込むため数秒〜数十秒かかります（進捗バーが出ます。2 回目以降はブラウザキャッシュで速くなります）。 キーボードが必要です。音が出ます。推奨: PC の Chrome / Edge / Firefox。
The first load fetches about 135 MB of asset packs and shows a progress bar. Keyboard required, audio on. Desktop Chrome / Edge / Firefox recommended.

OVERDRIVE — 対戦格闘 / Versus Fighting

  • 6 人のファイター、4 ステージ、ARCADE / VS CPU / VS 2P / TRAINING
  • 移動 WASD　弱 J　強 K　必殺 L　超必殺 U　投げ I　バースト O
  • ガトリングキャンセル、コマンド入力ボーナス、ジャストガード、ドライブバースト
  • 2P: 矢印キー ＋ NM,./;

NEON UPRISING — ベルトスクロール / Beat 'em up

  • 犯罪都市 BLACK VEIN を進み、5 区画 33 体の敵とボス IRON VOSS を倒すステージ 1
  • 移動 WASD　攻撃 / 拾う J　ジャンプ K　緊急技 L　投げ I
  • J 連打でパンチ → ボディブロー → アッパー（当たった時だけ次へ）。S を入れたまま 3 発目で投げに変化
  • 歩いて接近すると掴み。J で追撃、方向＋J で投げ。投げた敵は他の敵にも当たる
  • 木箱・ドラム缶から食料 / 現金 / 鉄パイプ
  • 前方向を2回（→→ / ←← / D D / A A）押し、2回目を保持してダッシュ。走行中 J / Z で強打＆確定ダウン

共通 / Common

  • H 技表・操作一覧　ESC ポーズ　ポーズ中 Q で戻る
  • 画面下のツールバーで BGM / SE / VOICE の音量とミュート
  • ゲームパッド・タッチ操作は未対応

技術 / Tech

  • HTML5 Canvas 2D、固定 60Hz 更新、1280×720 論理解像度
  • Web Audio API でローカル合成する 8 曲の BGM と効果音
