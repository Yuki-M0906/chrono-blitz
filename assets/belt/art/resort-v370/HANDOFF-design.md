## v3.15.0 再生

各体 `*-life.png`。6列×4行。絵の役割は v3.14.0 のまま。変えたのは、いつその絵を出すかと、歩行6コマの左右位置。

- 待機は平静、まばたき、笑顔、叫び、髪、挑発を、それぞれ読める長さで回す。双子は同じ待ちのあいだに予備、打撃、戻りも出す。攻撃判定は増えない
- 歩行は一歩の開始で位相を戻す。近い移動は同じ接地が続かない順。CORAL と PEARL は 6→7→9→7。ほかは 6→7→8→9。間合いが開いている移動だけ 10→11→8→11。速度そのものは変えていない
- 歩行と走行の胴はセルの x=128 に揃える。はみ出す姿勢はセル内で止める。待機の6コマは平静の胸が同じ位置に来る量だけまとめて横へ動かす。叫びと挑発は平静との位置関係を保つ。攻撃と被弾は動かしていない
- 予備は構えから深い構え。打撃は攻撃のたびにジャブ、クロス、蹴りを回す。当たりは ATK_H の 5F のまま
- 立ちやられはのけぞり、胸、頭。空中は頭、よろめき、回転。ダウンは回転のあと地面。起きは地面、よろめき、基本シートの膝、待機
- 掴みの出は追加シートののけぞりと胸、その後は基本シートの前屈。投げの上昇は回転
- 双子の連携は motion の各段。予備の終わりで2コマ目、リングは投擲のあいだに4コマ目、パラソルの2段目は突きの前に4コマ目。打撃と投擲の時刻は従来どおり

復元控えは `backups/v3.14.0/`。戦闘の威力、受付フレーム、敵AIの待ち時間は変えていない。

## v3.13.0 姿勢の対応

各体 `*-life.png`。6列×4行。倍率は立ち姿で1つ。足元は基本シートの待機と揃える。セルをまたがない。

- 0 待機。3 まばたき、1 笑顔、4 髪。5 は攻撃後の待ちで保持。2 は双子が相方を失ったときの叫び
- 6–9 歩行。速度に合わせて間隔を変える。10–11 は速い接近と双子の移動だけ
- 12–13 予備。14 ジャブは CORAL、15 クロスは AZURE、16 蹴りは PEARL。17 は戻り。当たりは ATK_H の 5F で、その間は同じ打撃を出す
- 18 軽いのけぞり。19 は重量級の胸。20 頭、21 よろめき、22 回転、23 地面
- 起きの膝と、掴み中の前屈は基本シート（21 と 18）。追加シートにその姿勢が無い
- 双子の連携は `*-motion`。各段を1つの武器攻撃にし、打撃と投擲の時刻に伸ばした姿勢を合わせる。単独時はもう一段も使う
- SUNSET / LAGOON / ORCHID は別画像を持たない。`beachPalette` が ID 先頭で衣装色だけ回す

戦闘の受付フレーム、威力、敵AIの待ち時間は変えていない。シートが読めないときは従来の24姿勢に戻る。

## 再開時に守る画像の契約

- 配布サイズは 1536×1024 の RGBA。6列×4行。公称セルは 256px。
- 読み込みは `prepareBeachAtlas`。左へ 96px はみ出した武器を隣セルから取る。セルを境界で切って貼ると槍やパラソルが欠ける。
- 色替えが肌まで及ばないよう、衣装の色を維持する。
  - CORAL: 赤が緑の 1.8 倍より強い画素だけ回転する
  - AZURE: 青が赤の 1.2 倍より強い画素
  - PEARL: 青が緑の 1.3 倍より強い画素
- マニフェストが実際に読むのは `pearl-transparent.png` と `*-motion-transparent.png`。
- 描画前の `cleanCell` は、いちばん大きい連結成分だけ残す。体から離れたリングは従来どおり消えることがある。

全件を `node tools/build-sprites.mjs` で埋込すると、HTML 内のエンジンソースまで書き戻す。機構を動かさない再開では、`beach-*` だけを `data/resort-actors.js` に再出力し、`?v=` をそのファイルの SHA-256 先頭10桁に合わせる。
