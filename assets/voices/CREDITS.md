# 音声クレジットと再利用条件

CHRONO BLITZ: OVERDRIVE v1.7.0 のキャラクター音声は、VOICEVOXによる合成音声です。

| ゲームの人物 | 音声クレジット |
|---|---|
| 神楽 | VOICEVOX:玄野武宏 |
| ヴォルト | VOICEVOX:白上虎太郎 |
| フレイヤ | VOICEVOX:四国めたん |
| タイタン | VOICEVOX:麒ヶ島宗麟 |
| 綾女 | VOICEVOX:中国うさぎ |
| セリーヌ | VOICEVOX:九州そら |

音声を再利用・配布する場合も、該当する上記クレジットを記載し、各音源の規約を守ってください。第三者へ音声の利用を許諾する際も、クレジットと規約遵守を引き継いでください。ゲームの人物はオリジナルで、音源キャラクターの画像は使用していません。

- [VOICEVOX ソフトウェア利用規約](https://voicevox.hiroshiba.jp/term/)
- [VOICEVOX 音声モデル利用規約](https://github.com/VOICEVOX/voicevox_vvm/blob/main/README.md)
- [玄野武宏・白上虎太郎・麒ヶ島宗麟の音源規約](https://www.virvoxproject.com/voicevoxの利用規約)
- [四国めたん・中国うさぎ・九州そらの音源規約](https://zunko.jp/con_ongen_kiyaku.html)

2026-11-08に上記規約を確認。ユーザーの明示的な規約同意を得て音声モデルを取得しました。生成環境は開発用の `tools/voicevox-runtime/` 内にあり、配布用HTMLには合成した音声だけを含めています。
